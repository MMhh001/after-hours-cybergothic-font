## Supported Characters (Incomplete Font Clearly Labeled)
- **Supported**: Full basic Latin uppercase `A–Z`, lowercase `a–z`, numerals `0–9`, space, and basic punctuation `. , - ! ? : ; ' " & / # @ ( )` (79 glyphs total).
- **Not supported**: Extended Unicode/accented characters (e.g., `é`, `ü`, `ñ`), currency glyphs, and mathematical operators beyond the list above are intentionally omitted in this v1.0 display cut.

## Consistent Style System Rules
1. **Gothic Vertical Architecture**: Every primary pillar uses a uniform `104`-unit stroke width (`94` units in lowercase) contrasted against slender `64`-unit horizontal bars (`1.63:1` weight ratio), echoing blackletter calligraphy.
2. **Pointed Arch Construction**: Rounded frames (`O`, `Q`, `o`, `g`, `0`, `@`) replace circular curves with faceted Gothic lancet arches, maintaining crisp silhouette sharpness without muddy curves.
3. **45-Degree Cyber Circuit Chamfers**: Terminal tops, bases, and crossbar tips all share repeating `32`-unit and `20`-unit 45-degree diagonal cuts, accented by glowing diamond core nodes (`A`, `M`, `i`, `j`) and a slashed `0`.
4. **Two Website Treatments Shown in `specimen-sheet.png`**:
   - **Hero Treatment (`132px`)**: Chromatic cyan/magenta split offset + neon underline rule for full-bleed dark-mode website hero banners.
   - **Heading Treatment (`64px` & mobile scale)**: Clean high-contrast bone-white rendering inside a sharp cyber frame with a tall `500`-unit lowercase x-height so headings stay crisp and legible on phone screens.

## Design Choices (3 Sentences)
We fused medieval Gothic vertical-to-horizontal stroke contrast (`104u` stems vs. `64u` crossbars) and pointed lancet arches with precision `45°` cyberpunk circuit chamfers so every letter looks like carved neon circuitry rather than an over-decorated gimmick. To guarantee phone readability alongside expressive hero energy, we set a generous `500`-unit x-height with open rectangular counters and separated the neon split-layer effect from the core `.otf` vector geometry. That way, the exact same installable font shifts effortlessly from a glitch-lit hero centerpiece to clean, readable subheadings on any personal website.
