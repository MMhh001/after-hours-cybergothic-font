# After Hours CyberGothic (`.otf`)

An original Gothic-Cyberpunk Latin display typeface built for web hero headers and mobile-legible subheadings.

- **Download Font**: [`AfterHoursCyberGothic.otf`](https://raw.githubusercontent.com/MMhh001/after-hours-cybergothic-font/main/AfterHoursCyberGothic.otf)
- **Specimen Preview**: [`specimen-sheet.png`](./specimen-sheet.png)

## Supported Character Coverage (Incomplete Display Set — Explicitly Labeled)
- **Included**: Uppercase `A–Z`, lowercase `a–z`, numerals `0–9`, space, and basic punctuation `. , - ! ? : ; ' " & / # @ ( )` (79 glyphs total including `.notdef` and `space`).
- **Not included (incomplete font)**: Extended Latin diacritics/accents, currency symbols other than `#`/`@`, and non-Latin scripts.

## Design System Rules
1. **Gothic Bones**: Heavy `104`-unit vertical pillars paired with `64`-unit crossbars (`1.63x` contrast ratio) and pointed arch roofs on `O`, `Q`, `o`, `g`, and `0`.
2. **Cyberpunk Cuts**: Consistent 45-degree `32`-unit chamfered terminals, angled `0` core slash, and core diamond accents inside `A` and `M`.
3. **Mobile Readability**: Generous `500`-unit lowercase x-height (`0.69x` cap height), open counters, and clean spacing down to 18px on mobile viewports.
